# 気象庁天気図の読み方(ヤマビヨリ 天気図読解ステップ用リファレンス)

`fetch_jma_weather_map()` が保存するのは気象庁「天気図」ページのデフォルト表示(実況、日本周辺カラー)。600×581px、およそ経度110〜160°E・緯度20〜50°N相当の範囲(画面四隅の経緯度線ラベルで確認可能)。このファイルは、その画像をClaude Codeが読んで点予報を補足コメントするときの手がかり。

## 基本記号

| 記号 | 意味 |
|---|---|
| 高(青字)+ 中心気圧数字 | 高気圧の中心。一般に下降気流・雲が少ない・晴天をもたらす。 |
| 低(赤字)+ 中心気圧数字 | 低気圧の中心。上昇気流・雲や降水が発達しやすい。 |
| 熱低(赤字) | 熱帯低気圧。台風になる手前、または台風から弱まった状態。進路次第で数日後に影響が出うる。 |
| ×(高/低の近く) | その気圧系の中心点マーカー。 |
| 前線(半円が並ぶ・赤) | 温暖前線。通過後は気温上昇、通過前は層状の雲・弱いが長く続く降水になりやすい。 |
| 前線(三角が並ぶ・青) | 寒冷前線。通過時に積乱雲・強い雨や雷、通過後は気温低下・北よりの風になりやすい。 |
| 前線(半円+三角が交互・赤青) | 停滞前線。ほぼ動かず、ぐずついた天気が長引きやすい(梅雨前線など)。 |
| 前線(紫、半円+三角) | 閉塞前線。寒冷前線が温暖前線に追いついた状態。 |
| 細い等圧線(黒、4hPa間隔) | 間隔が狭いほど気圧傾度が急=風が強い。等圧線が混んでいる場所の山は稜線風速が高くなりやすい。 |

## 移動速度・状態表記

- 「ゆっくり」: 目安の時速表記がないほど遅い動き。数日、似た気圧配置が続く可能性がある。
- 「ほとんど停滞」: 実質動いていない。前線と同様、長引く天気パターンのサイン。
- 「◯◯km/h」: その気圧系の移動速度。速い(目安40km/h以上)場合、点予報の翌日以降の値が今の配置から大きく変わりうる。

## 対象の山の位置の当たり方

1. `MOUNTAINS` の `lat`/`lon` から、画面四隅の経緯度線を基準におおよその位置を当てる。目安の線形換算式(画像は600×581px、左端が東経110°・右端が東経160°、下端が北緯20°・上端が北緯50°という前提。気象庁の標準構図に基づく近似で、正確な投影法ではないので目安として使うこと):
   - `x_px ≈ (lon - 110) / 50 * 600`
   - `y_px ≈ (50 - lat) / 30 * 581`
   - 例: 富士山(剣ヶ峰)(35.3606, 138.7274) → x≈345px, y≈284px(画面中央よりやや右・ほぼ中央)。
2. その座標に最も近い高気圧/低気圧の中心、または最も近い前線を探し、「対象の山がどの気圧系の影響下にあるか」を判断する。
3. 高気圧に近ければ「下降気流で雲が少ない」、低気圧・前線に近ければ「上昇気流で雲・降水が発達しやすい」という定性的な結びつけを、点予報の雲量%・降水確率%と照らし合わせて説明する。
4. 風向の参考: 北半球では高気圧から時計回りに吹き出し、低気圧には反時計回りに吹き込む。点予報の風向(`wind_dir_*`)と天気図上で推定される風向が大まかに整合するかも、位置判断の妥当性チェックに使える。

## 読解のスタンス(過信しないこと)

- これは目視による**定性的な補足**であり、点予報の数値を置き換えるものではない。「〜と考えられる」「〜の影響を受けている可能性がある」程度の確度で述べ、断定しすぎない。
- 上記の座標変換は近似(気象庁の実際の図法は単純な等間隔ではない可能性がある)。中心からかなり離れているように見える場合は「大まかに影響下にある」程度に留め、ピクセル単位の厳密な判定はしない。
- 天気図は取得時点の**実況**のみ(予想天気図タブは今回のスコープ外)。数日後に接近しうる低気圧・熱帯低気圧が画面内に見えていれば、点予報の14日先の数値には表れにくい中期的な懸念として言及してよいが、進路予測そのものはこのツールの役割ではない(気象庁の台風情報等への言及に留める)。
