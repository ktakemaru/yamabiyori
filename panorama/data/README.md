# 山名辞書(展望図用)

このフォルダの `hyakumeizan.json`・`mountains76.json`・`similar_names.json` は、展望図に出す山の名前と格(日本百名山・ヤマビヨリの 76 座)を決めるための辞書です(座標と標高は入れていません)。山頂の点は `summits.json` です(下)。

- `hyakumeizan.json`: 日本百名山と「日本の主な山岳標高」の山との対応(呼び名つき)
- `mountains76.json`: ヤマビヨリの 76 座(`mountain_weather_core.MOUNTAINS`)と「日本の主な山岳標高」の山との対応
- `similar_names.json`: 似た名前の山の組(名前の取り違えを防ぐため)

出典: 「日本の主な山岳標高」(国土地理院)と `MOUNTAINS` をもとに作成(加工: 百名山・76 座との対応づけ、呼び名)。
作り方は実験の `experiments/panorama/stage2_dictionary_build.py`(段階2)。

## 山頂の点(`summits.json`)

`summits.json` は、日本百名山とヤマビヨリの 76 座に当たる山頂の点(山頂名・呼び名・緯度・経度・標高・格・山の ID)です。

出典: 「日本の主な山岳標高」(国土地理院)をもとに作成。
加工: 日本百名山とヤマビヨリの 76 座に当たる山頂の点を抜き出し、呼び名を付けた。取り出した日付はファイルの `extracted`(2026-11-20)。
緯度・経度・標高は表の値のまま(丸め・足し算なし)。作り方は `tools/build_panorama_summits.py`(手元に表があるときだけ動く)。

76 座のうち表に当たる点の無い山(11 座)は入れていません。図では `MOUNTAINS` の座標を使い、「山頂の点は目安です」と書きます。

「日本の主な山岳標高」の表の全部はリポジトリに入れていません。展望図は、利用者の手元に
`cache/panorama/gsi_1003/*.geojson` があればそれを読み、そのほかの山の名前も出します。無ければ `summits.json` を読み、
名前は日本百名山と 76 座だけで図を作ります(図に「名前は日本百名山とヤマビヨリの 76 座です」と書きます)。
