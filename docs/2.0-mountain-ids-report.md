## 6. コンシェル側・ほかのビヨリへの申し送り

- **ビヨリコンシェル** `collect/yamabiyori.py` の `load_mountains()` は今、`MOUNTAINS` を ast で読み、`id` を並び順から `f"m{i + 1:03d}"` で作っている(読むだけで確かめた。書き換えていない)。今回の ID は今の並び順の番号と同じ値なので、**今のままでも結果は同じ**。`MOUNTAINS` の `id` を読む形(`m["id"]`)に変えれば、並べ替え・欠番に強くなる(コンシェル側の変更は今回は行わない)。`ast.literal_eval` は新しい `"id"` の項目があっても読める。
- 同じファイルの `--json-out` の検査(`ROW_REQUIRED` があるか)は、項目が増えても通る形。`details.native_row` に `id` が 1 つ増えて入る。
- **イキモノビヨリ** の `yamabiyori:m001` の参照は、そのまま正しい山を指す(番号を変えていないため)。
