# v1.10.0 リリースノート(下書き)

作成 2026-11-19、2026-11-20 に展望図の仕上げ(山頂の点・名前の置き方・雲の値・帯)に合わせて直した。**下書き**です。`.claude-plugin/plugin.json` の `version` と `CHANGELOG.md` はまだ変えていません(リリースの判断は作者)。
対象: v1.9.2(2026-11-15)のあと main に入ったもの(山の ID・Open-Meteo の利用上限への対応・14 座の座標の修正と唐松岳の参照日)と、
このブランチ `feature/panorama-diagnose` の展望図。詳しい経緯と数値は `CHANGELOG.md` の [Unreleased] と各報告書。

## 新しく使えるもの

### 天気入りの展望図(診断モードの `--panorama`)
- `mountain_weather_detail.py --mountain 山 --panorama` で、診断のあとに、その山の山頂から見た翌日の 6・8・10・12 時の雲を重ねた展望図
  (HTML 1 枚。外の読み込みなし)を `out/panorama/<山の ID>.html` に書く。山頂から 300m 以内に OpenStreetMap の展望地があれば、展望地の図も。
- 76 座だけ。76 座に無い山(`--name`)では「展望図は 76 座だけです」と出し、診断はそのまま。
- スマートフォンでは縮尺(広く・標準・拡大)・◀▶・指でなぞる、で見る。富士山が見える山頂では、富士山を含む方角で開く。
- 初回は、その山のまわりの国土地理院の標高タイル(約 560 枚・約 300MB)を取るので約 12 分かかる。2 回目からは約 20 秒。
- **日本百名山とヤマビヨリの 76 座の名前は、はじめから出る**(国土地理院「日本の主な山岳標高」のうち、百名山と 76 座に当たる山頂の点だけを
  `panorama/data/summits.json` に入れた。出典と加工を図とファイルに書く)。そのほかの山の名前は、利用者が同じ表を `cache/panorama/gsi_1003/` に
  置いたときだけ出る。76 座のうち表に点の無い 11 座は、山頂の点が目安(図に書く)。
- 名前は、「広く」「標準」では重ならずに置ける分だけ出す(百名山 → 76 座 → そのほか、近い山から。富士山は見えれば必ず出す。置けない山は点だけで、
  図の下に「名前を省いた山があります。『拡大』で出ます」)。「拡大」では見えている百名山と 76 座を全部出す(横向きの画面ではページを縦に送る)。
- 山頂の雲量(名前の横の「雲 NN%」・名前のうすさ・山にかかる丸い雲)は、山頂をはさむ 2 つの気圧面の雲量のうち大きいほう(雨の日に山頂の雲が
  薄く出ていたため)。診断の文・`--json-out` の雲量は今までどおり。雲の帯は、同じ方位で重なる帯をまとめ、濃さの合計を 0.85 までにした。
- 展望図が作れなくても、診断の出力・`--json-out`・終了コードは変わらない(最後に理由の 1 行)。`--panorama` を付けなければ何も変わらない。
- 予報にもとづく目安で、写真との答え合わせは少数(14 枚)。

### 山に変わらない ID(2026-11-16)
- `MOUNTAINS` の各山に `"id"`(`m001`〜`m076`)。`--json-out` に `id` が入る。診断モードの `--mountain m012` のように ID でも選べる。
- スコア・予報の数字・画面の出力は変わらない。

## 変わったもの

### Open-Meteo の利用上限(HTTP 429)への対応(2026-11-16)
- 429 を種類(1 分・1 時間・1 日・不明)で分け、画面に 1 行出す。1 分の上限は 65 秒待って取り直す(1 回の実行で 5 回まで)。
- 探索モードは通信の間隔を自動で調整する(以前より時間がかかる)。1 時間・1 日の上限に当たったら、残りの山の取得をやめて、取れた山だけで結果を出す。
- 診断モードの既定の動きは変わらない(`--panorama` のときだけ、展望図の通信に間隔の調整を使う)。

### 14 座の座標の修正(2026-11-18)— **点数が変わりうる**
- 唐松岳・金峰山・瑞牆山・榛名山(掃部ヶ岳)・霧ヶ峰(車山)・塔ノ岳・赤城山(黒檜山)・雲取山・常念岳・安達太良山・男体山・木曽駒ヶ岳・妙高山・
  八ヶ岳(赤岳)の座標を、国土地理院「日本の主な山岳標高」の山頂の点に直した(山頂から 300m 以上ずれていた。唐松岳は白馬岳の近く、金峰山は北奥千丈岳の上にあった)。
- **この 14 座は、予報を取る地点が変わるので、同じ日でも v1.9.2 と点数が変わることがある**(例: 直した日の比べで、雲取山は 3 日間の点数が 4〜5 点上がり、
  安達太良山の 1 日は 0.0 → 28.6)。直していない 62 座は変わらない。スコア式・閾値は変えていない。
- 地形の見取り(`terrain_profiles.json`)を 14 座だけ作り直した。

### 参照日の唐松岳(2026-11-18)
- 回帰テストの参照日(唐松岳 2026-09-06)の見本を山頂の点で取り直し、期待値を 55.0 → 46.0 に直した(座標の修正のあとも、見本の中身が白馬岳の近くのデータだったため)。
  立山・槍ヶ岳の参照日の値は不変。

## 互換性
- 既定の動作(引数なし・`--panorama` なし)の出力の形は v1.9.2 と同じ。`--json-out` に `id` が増えた(既存の項目は不変)。
- 新しい依存パッケージは無い(展望図は既存の numpy・requests を使う)。

## 未確認・注意
- 展望図は、実機のスマートフォン・Safari・Firefox では見ていない(headless の Edge で 3 通りの画面の大きさを確かめた)。
- 名前の多い山頂(富士山・立山など)では、「広く」「標準」で名前を出さない山が多い(点だけ)。「拡大」では名前と引き出し線が重なる所が残る。
  幅 900px 以上の画面(パソコン)は、全周を横に送る前からの形のままで、名前と引き出し線の重なりが残る(富士山の図で 89 組)。
- 国土地理院の「日本の主な山岳標高」の表の全部はリポジトリに入れていない(入れたのは百名山と 76 座に当たる山頂の点だけ。2026-11-20 の作者の決定)。
