### 1.2 診断モードの引数(`mountain_weather_detail.py`)
- `--panorama`: 診断のあとに展望図を書き、最後に「展望図: <パス>」と「(展望図の通信: 標高タイル N 枚・Open-Meteo N 回(重さ)・Overpass N 回。かかった時間)」を出す。
  代わりの動きをしたときは、その理由も 1 行ずつ。
- `--panorama-out <パス>`: 出力先(展望地の図は名前の後ろに `v`)。既定は `out/panorama/<ID>.html`・`<ID>v.html`。
- `--panorama-out` だけ・`--list` と `--panorama` は引数の誤り(終了コード 2。ほかの引数と同じ扱い)。
- 76 座に無い山(`--name` ほか)に `--panorama` を付けると「展望図は 76 座だけです」と出し、診断はそのまま。
- 展望図のどこで失敗しても、診断の出力・終了コードは変えず、最後に「展望図は作れませんでした(理由)」。`--out` のときは、この行もファイルに入る。
- 日付は翌日(診断モードに日付の引数が無いため)。6・8・10・12 時と「地形だけ」。開いたときは 8 時。
- 診断モードの既定の動き(`--panorama` なし)は変えていない(テストと、実際の出力の比べ)。
