## 1. 結果
**完了**(止める条件には当たっていない。おまけの写真Eまで実施)。

**一言の結論: 言い当てられた。** 材料(国土地理院の1003山)に名前がある山は、写真4枚の51ラベルすべてで名前と標高が一意に一致した。
計算した方位から求めた横位置は、PeakFinder の引き出し線と中央値 0.6〜1.9px、最大 11px で重なった。
並び順の入れ替わりは 0 件。写真の視点の標高(写真に表示された値)を使うと、ラベルのある山はすべて「見える」(余裕が正)になった。
ただし余裕が 0.1° に満たない山が多く、**「見えるか」の結論は視点の標高と、足もと 100〜200m の地形の扱いで変わる**(3章)。
また、途中の地形を取る刻みを変える(一律 100m)と、雷岩からの候補 425 座のうち余裕 0.1° 未満の 8 座で結論が変わった(写真のラベルの山は変わらない)。
段階2へ進んでよい結果だと考える。そのうえで、足もとの扱いと刻みを決めるのが先(7章)。

山とラベルの対応は**名前と標高だけで付け、方位は使っていない**。だから、横位置の残差と並び順は、対応とは独立した確かめになっている。

## 2. 答え合わせの成績
横位置の当てはめは `x = cx + f·tan(方位 − 中心)`(3つの値を最小二乗で求めたもの)。残差は |px|。
「不確か」(同じ名前・同じ標高の候補が複数)は 0 件だったので、不確かを除いた成績も同じ値になる。

| 写真 | 対応 / 全ラベル | 並び順 | 残差 中央値 / 最大 | 20px 以内 | 画角(横) | 余裕が負 |
|---|---|---|---|---|---|---|
| A | 10 / 16 | 9/9 一致 | 1.9 / 6.0 px | 10/10 | 62.95° | 0 |
| B | 13 / 18 | 12/12 一致 | 1.3 / 10.0 px | 13/13 | 62.71° | 0 |
| C | 14 / 15 | 13/13 一致 | 1.1 / 11.0 px | 14/14 | 62.78° | 0 |
| D | 14 / 15 | 13/13 一致 | 0.6 / 8.5 px | 14/14 | 62.70° | 0 |
| E(おまけ) | 6 / 19 | 5/5 一致 | 0.3 / 1.4 px | 6/6 | 62.72° | 0 |

- 合格の目安(並び順 95%・20px 以内 90%・余裕が正 90%)は、4枚とも満たした(どれも 100%)。ただし分母は**対応が付いたラベルだけ**で、対応が付かなかったラベル(A 6・B 5・C 1・D 1)は成績に入っていない。
- 当てはめの3通りを比べた(rms は px)。
  - 3つの値を求めるもの: rms 2.8〜3.3、中心の位置 `cx` = 781〜821。
  - `cx` を 800 に固定したもの: rms 3.0〜3.5、画角 62.78〜62.81°。
  - 方位に比例する直線: rms 9〜12.5、画角 66.3〜66.6°。
  - 直線は画面の端ほど外れる(端のラベルで 20〜29px)。tan の形のほうが合う。4枚の画角が 62.7〜63.0° にそろっているのも、当てはめが安定している根拠になる。
- `cx` と中心の方位は、互いに打ち消し合って決まりにくい(写真Aで `cx` が 821、Bで 781)。`cx` を 800 に固定しても残差はほぼ変わらない。

### 輪郭の確かめ(指示書 5.3 の 5)
対応が付いた山の方位で、計算した輪郭(150km まで)を見た。
- 富士山・毛無山・大無間山・青薙山・笊ヶ岳・南アルプスの 3000m 峰・甲斐駒ヶ岳・御嶽山・経ヶ岳・乗鞍岳・十石山: **その山自身が輪郭を作っている**(輪郭の距離が山の距離と同じ)。
- 黒岳・黒岳＜釈迦ヶ岳＞・篠井山・身延山・三ツ峠山・櫛形山: **山頂は手前にあり、輪郭はその奥のもっと遠い山が作っている**。たとえば櫛形山(47km)の奥は 60km の南アルプス、黒岳＜釈迦ヶ岳＞(23km)の奥は 84km の山。写真でも、これらの山は遠い山並みの下に重なって写っている。

## 3. 合わなかったところと、その原因の見立て
1. **櫛形山だけ、3枚(B・C・D)そろって +8.5〜11px(+0.3〜0.4°)ずれる**。
   - 写真Dを拡大して確かめたところ、引き出し線は x≈163(記録は 162)だった。読み取りの誤り(±10px)ではない。
   - 距離が約47km なので、ずれは横方向に約300m にあたる。原因は**座標の違い**とみる。PeakFinder が使う山頂の位置と、1003山の点(三角点 2052m)が違う。櫛形山は山頂が平らで長い山。
   - 確かめてはいない。
2. **富士山 +5.5〜6px・三ツ峠山 −4.7px** は、読み取りの誤差の範囲と見る(写真Aは残差がやや大きい)。
3. **「見えるか」が、視点の標高でひっくり返る(指示書 5.1 の3通り)**。
   - 写真Dでは、地理院タイルの標高(2027m)を使うと、経ヶ岳・鎌ヶ峰・乗鞍岳・十石山が「見えない」になる。写真の表示値(2030m)と GPS の値(2034m)では見える。
   - 原因は**足もと 100〜150m のタイルのセル**。この方向のセルは 2029m で、目の高さとほぼ同じ高さなので、遠い山(見上げ角が −0.2° 前後)を隠してしまう。
   - 雷岩からの計算(200km 以内の 426 座)では、視点の標高で結論が変わる山が 20 座あった(丹沢・高尾山・陣馬山・房総の山など東〜南東の山が大半。ほかに南の御正体山・箱根 神山、北の至仏山)。
     表示値 2030m では 20 座とも隠れ、GPS 2040m では 20 座とも見える。地理院タイルの標高(2032.7m)では 14 座が見え、6 座(権現山・扇山・御正体山・陣馬山・高尾山・箱根 神山)が隠れる。
     表示値 2030m で隠れるときの手前の地形は、20 座のうち 17 座が視点から 100m 先のセルだった(御正体山・箱根 神山は 3.4km 先、至仏山は 11.8km 先)。
   - 雷岩から試した結果(表示値 2030m で、取らない範囲を 100 → 200m に広げた場合):

     | 山 | 視点から 100m 以内を取らない(今回の既定) | 200m 以内を取らない |
     |---|---|---|
     | 蛭ヶ岳 | 余裕 −0.05° | 余裕 +0.42° |
     | 大室山 | 余裕 −0.27° | 余裕 +0.57° |
     | 高尾山 | 余裕 −1.66° | 余裕 +0.07° |
     | 浅間山 | 隠れる(手前の地形は 0.2km) | 隠れる(手前の地形は 0.2km のまま。300m にすると 18km 先の奥秩父) |

     視点を 2040m にした場合は、100m・200m・300m のどれでも、表の 4 座は「取らない範囲 300m」のときと同じ結果になった(浅間山は 18km 先の奥秩父に隠れる)。
   - 雷岩の南東側で、タイルの粗さ(76m)が「自分の足もとの地面」を壁に見せている。
   - 南アルプス・八ヶ岳・木曽駒ヶ岳など西側の結論は、どの組み合わせでも変わらない。
   - 雷岩からの輪郭(方位 150〜310°)で、1km より近い地形が輪郭を作っているのは、方位 150.0〜151.3° の 14 方位だけ。輪郭の図(`skyline_raiiwa.svg`)は、ほぼ全体が遠くの山並みを描いている。
   - **今回の数値(写真の表示値・100m)はそのまま報告し、変えていない。**
4. 写真Aの右端(方位 240〜246°)には、聖岳・赤石岳・悪沢岳が写っている(雪の山として見える)のに、PeakFinder はラベルを出していない。計算では見える。**PeakFinder 側が、画面の端でラベルを間引いた**と見る。
5. 対応が付かなかったラベルの原因はすべて「材料に無い」(5章)。名前が合っていて標高だけが合わない、という食い違いは 1 件も無い。

## 7. 次の段階への申し送り
- **足もとの扱いが最優先**。
  - z11(76m)のタイルでは、視点から 100〜200m 以内のセルが、遠くの低い角度の山の「見える・見えない」を左右する。
  - 段階3の前に、次のどれかを決める必要がある。
    - 視点の近く(例 300m 以内)だけ、細かい標高タイル(z14・約 10m や 5m メッシュ)を使う。
    - 取らない範囲を 200m 程度に広げる。
    - 視点の標高を「周りのセルの最大+α」にする。
  - 遠い山の判定と横位置は、z11 で十分だった。
- **段階2(山名辞書)に要る材料**:
  - 1003山に無い山: 御坂山地の中藤山・鬼ヶ岳・三方分山・お坊山、笹子雁ヶ腹摺山・牛奥ノ雁ヶ腹摺山、南アルプス前衛の生木割山・水ヶ森、東側の奥多摩・中央線沿線の低い山の大半。
  - 山以外の目印: 峠・台地・湖・ダム(写真Aにダム湖が写っている)・町。
  - 同じ名前の山(駒ヶ岳・黒岳・毛無山・北岳など)は、標高を付けると今回はすべて一意に決まった。辞書でも標高を名前と組にして持つのがよい。
- **段階3(図に出す山の選び方)の手がかり**:
  - PeakFinder がラベルを出した山は、見上げ角が −1.1〜+2.1°(富士山が +2.1°、それ以外は +1.0° まで)、距離 22〜125km、余裕 0.006〜0.75°。余裕の大きさでは選んでいない(+0.006° の鎌ヶ峰も出している)。
  - 効いていそうなのは「よく知られた名前か」と「画面の上でラベルが重ならないか」。
  - 計算では見えるのにラベルが無い 2500m 以上の山が 1 枚に 10〜25 座ある。図に出す山は、有名度(辞書の格)で絞る必要がある。
- **計算の刻み**: 今回は 2km まで 50m・20km まで 200m・その先 500m。手元のタイルだけで、一律 100m の刻みに変えて計算し直した(`out/panorama/daibosatsu/step_check_100m.txt`)。
  - 写真のラベルの山(57 件。おまけを含む): 結論が変わったものは 0 件。余裕の変化は最大 0.16〜0.46°。
  - 雷岩からの候補 425 座: 結論が変わったのは 8 座で、どれも見える→隠れる。硫黄岳・駒津峰・板屋岳・十枚山・高ドッキョウ・不動岳・袈裟丸山・庚申山で、元の余裕は +0.003〜+0.098°。
  - 余裕の変化は、中央値 0.03°、最大 2.35°。大きく変わったものは、近く(2km 以内)の刻みが 50m から 100m に粗くなったためと見る(確かめていない)。
  - **余裕が ±0.1° 以内の山は、刻みと足もとの扱いで結論が変わりうる**。展望図では「ぎりぎり」と表示を分けるのがよい。遠くの刻みは 200m 以下にするのが安全。
- 横の画角(この機種・この構図で約 62.8°)が分かったので、同じスマホの写真なら、ラベルが 2〜3 個あれば方位を合わせられる。
